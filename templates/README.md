# Templates

`everglades.pptx` in this folder is **Claude Slide Template 2026**. The rebrand engine inspects it as the server template.

The deck is 12 designed sample slides on the Blank layout (the Office master layouts are unused). The same layouts are drawn in both palette colors — **Green** is `7FAE29`, **Blue** is `04B1D2`. Staff pick one in the converter; convert clones that series for the whole rebuilt deck. Title slides exist only in green and are recolored when Blue is selected. Neither option is dropped from the template.

If you are given a `.potx` instead, drop it here as `everglades.potx` — `rebrand/inspect_template.py` rewrites it to `.pptx`. `npm run template` builds a python-pptx starter for engine development only; do not use it in place of this official file.
