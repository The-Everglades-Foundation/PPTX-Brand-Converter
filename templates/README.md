# Templates

`everglades.pptx` in this folder is **Claude Slide Template 2026**. The rebrand engine inspects it as the server template.

The deck is 12 designed sample slides on the Blank layout (the Office master layouts are unused). Convert clones those sample slides. There is no Green/Blue picker.

If you are given a `.potx` instead, drop it here as `everglades.potx` — `rebrand/inspect_template.py` rewrites it to `.pptx`. `npm run template` builds a python-pptx starter for engine development only; do not use it in place of this official file.
